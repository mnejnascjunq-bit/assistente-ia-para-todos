# 🤖 Assistente Virtual: Inteligência Artificial para Todos

Assistente educativo desenvolvido em **Python** e **Streamlit** como parte do projeto de extensão **Inteligência Artificial para Todos**, com o objetivo de democratizar o acesso seguro, ético e prático à IA generativa para estudantes e microempreendedores locais.

## 🎯 Funcionalidades Principais

* **Consulta Direta ao Guia (`pypdf`):** Responde com base exclusiva no folder oficial (`Inteligencia_Artificial_para_Todos.pdf`).
* **Atalhos de Início Rápido:** Botões interativos para segurança digital, criação de prompts comerciais e apoio aos estudos.
* **Acessibilidade Inclusiva:** Leitura em voz alta sob demanda (`gTTS`) e área dedicada para tradução em Libras (**VLibras**).
* **Segurança e Ética:** Reforça a proteção de dados pessoais, checagem de fatos e o protagonismo humano.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python 3
* **Interface Web:** Streamlit
* **Inteligência Artificial:** Google GenAI SDK (`gemini-3.8-flash`)
* **Leitura de PDF:** `pypdf`
* **Áudio em Voz Alta:** `gTTS`
